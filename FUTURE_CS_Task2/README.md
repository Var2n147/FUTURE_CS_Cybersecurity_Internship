# Task 2 – Phishing Email Detection & Awareness System

## Objective

The objective of this task is to analyze phishing email samples, identify
common phishing indicators, classify email risk, and develop practical
security awareness guidelines that help users recognize and avoid phishing
attacks.

## Scope

The analysis focuses on:

- Sender and domain examination
- Email subject and message content
- Social engineering indicators
- Suspicious URLs
- Email headers where available
- Risk classification
- User awareness and prevention

## Methodology

The following process is used:

1. Collect suitable phishing email samples.
2. Preserve the samples in a safe, sanitized form.
3. Examine sender information and email content.
4. Analyze available email headers.
5. Inspect suspicious URLs without visiting potentially malicious
   destinations.
6. Identify phishing indicators.
7. Classify the risk as Safe, Suspicious, or Phishing.
8. Document findings in simple language.
9. Provide prevention and awareness recommendations.

## Tools

- Linux
- Email header analysis tools
- Browser-based security tools
- Git and GitHub
- Markdown
- PDF documentation

## Deliverables

- Phishing email samples
- Individual analysis records
- Evidence/screenshots
- Phishing Detection & Awareness Report
- Prevention guidelines

## Safety Notice

Live malicious links are not intentionally opened during this analysis.
Suspicious URLs are represented in defanged form where appropriate.

## Disclaimer

This project is completed for educational and authorized internship
purposes using public or controlled phishing samples.
