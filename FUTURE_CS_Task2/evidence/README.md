# Task 2 – Evidence

This directory contains supporting evidence for the phishing email
detection and awareness assessment.

## Evidence Included

### 1. Sample Analysis

The `analysis/` directory contains individual analysis records for:

- Sample 01 – Account Lockout
- Sample 02 – Microsoft Password Expiration
- Sample 03 – Apple App Store Purchase

Each analysis documents the source, phishing indicators, classification,
attack explanation, limitations, and recommended user actions.

### 2. Sanitized Samples

The `samples/` directory contains sanitized representations of the
analyzed examples.

Potentially dangerous URLs are defanged where applicable using `[.]`.

### 3. Report

The `report/` directory contains:

- `Phishing_Detection_Awareness_Report.md`
- `Phishing_Detection_Awareness_Report.pdf`

The PDF is the primary presentation-ready deliverable for this task.

## Safety

No potentially malicious URL or attachment was intentionally opened
during this assessment.

The evidence is intended for educational and authorized cybersecurity
analysis only.
