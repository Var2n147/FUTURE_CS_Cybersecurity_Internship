TASK 2 – PHISHING EMAIL SAMPLE 02

Sample ID:
FUTURE-CS-T2-002

Source:
SeanWrightSec/phishing-examples
Public educational phishing example

Category:
Credential phishing / password expiration

Claimed Sender:
Organization IT Department

Subject Theme:
Password expiration / immediate password update

Message Theme:
The recipient is informed that their organizational password has expired
or is about to expire and is instructed to use a link to update it.

Suspicious Element:
The message directs the recipient toward a password-update link that
does not use a trusted organizational domain.

IMPORTANT:
This is a sanitized description of a publicly documented phishing
example. Original third-party content has not been copied into this
repository.

URL Safety:
Potentially suspicious URLs are represented in defanged form where
applicable and are not intentionally opened.
