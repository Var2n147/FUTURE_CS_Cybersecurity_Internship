## Public Phishing Sample Repository

SeanWrightSec – phishing-examples

https://github.com/SeanWrightSec/phishing-examples

This repository contains educational examples of real phishing messages,
including:

- Microsoft password-expiration phishing email
- Apple App Store phishing email
- Coinbase phishing SMS
- Voicemail phishing SMS

The repository was used as a reference for phishing-email structure and
indicators. Original content is not claimed as our own.
